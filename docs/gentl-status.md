# GenTL Status and Limitations

GenTL is a default-off, internal, read-only backend foundation. It is not a
selectable streaming backend. See the [current backend/profile matrix](status.md#backend-and-camera-profile-matrix)
for implemented and unavailable paths.

The [GenTL evidence index](qualification-evidence.md#gentl-producers-and-consumer)
separates controlled fixtures and producer investigations from hardware
qualification. Find the original probe, producer, and wire records under
[Backend and Transport Experiments](backend-transport-experiments.md).
